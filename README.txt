Cardly anatomy flashcards

Open index.html in your browser. The 292-card Dorian anatomy deck is
already included; no server, account, or internet connection is needed.

Use Reveal answer or Space to switch sides. Use the arrow buttons or
Left/Right keys to navigate. Shuffle randomizes the current deck.

Controls appear above the card. Rate each card Hard, Good, or Easy.
Choose All, Hard, Good, or Easy in the study header to study that group.
The group counts update when you change a rating. Restart returns to
the first card in the current group without erasing ratings.

Ratings, current card, shuffled order, selected group, and answer
visibility are saved per deck in browser local storage. Reopening the
page resumes the built-in deck; re-importing another deck restores its
saved study progress. Use the same browser and page location to resume.
Clearing browser storage removes saved ratings and progress.

Import Anki deck accepts .apkg files (including files with no extension).
You can also drag a deck onto the page. Import happens on your device.
Imported deck files and media are held for this session; reopening the
page restores the built-in anatomy deck. Their study progress remains
saved for the next time you import the same deck.

Supported templates: standard field-based cards, cloze deletions, and
the supplied deck's image question/answer overlays. Templates requiring
Anki add-ons or JavaScript are not executed. For newer compressed Anki
packages, re-export using “Support older Anki versions”.

Keep index.html, flashcards.js, anatomy-deck.js, deck-media/, and vendor/
together when moving the app. index_orig.html and the source deck are
unchanged.
